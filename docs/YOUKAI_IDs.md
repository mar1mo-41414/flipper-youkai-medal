妖怪が紐付いているアーク種別 (79 件)。v2.2.0 の RomFS `gamedata/nfc/nfc_lottery_config.cfg.bin` (`NFC_INFO`) から抽出。

> このファイルは
> [switch-youkaiwatch4-medal の docs/YOKAI_IDS.md](https://github.com/mar1mo-41414/switch-youkaiwatch4-medal/blob/main/docs/YOKAI_IDS.md)
> のコピー。抽出の手順や解析の詳細はそちらを参照。

- **ID**: 保護データ平文の 5〜7 バイト目 (36 進 3 文字)。このアプリの **Create new ark (YW4)** や
  **Change ID**、`make_nfc.py --id` に入れる値
- **No.**: シールの番号 (`int(ID, 36) − 28652`)。計算上マイナスになるものは `----` (作るときは `0000` になる。ゲームは見ていない)
- **制限**: 空欄 = 同じ UID は 1 回限り。`1日` = 1 日 1 回の別枠 (flag 非 0)
- 同じ妖怪に複数の ID があるもの (ジバニャン: M3I / M88 / M8M など) の違いは未確認。ゲームでは M88 = ジバニャンを確認済み
